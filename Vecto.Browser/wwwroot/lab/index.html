Rust Covecto/VTracer vs DikaTracer vs Vector Magic · eksperimen lokal, bukan engine default

1. Pilih sumber dan kandidat

File diproses di browser, bukan dikirim ke server. Jika input lebih besar dari resolusi pilihan, hanya hasil Rust yang ditracing pada resolusi tersebut; file DikaTracer/Vector Magic tidak diubah. Semua SVG dirender ulang pada ukuran evaluasi yang sama untuk perbandingan. PixelExact sengaja dibatasi untuk ikon kecil agar JPEG kompleks tidak menghasilkan puluhan ribu path.

Pilih input asli. Engine eksperimen belum aktif sampai benchmark dijalankan.

2. Hasil pengukuran

Penilaian: MAE warna + SSIM lokal 8×8 + error warna aksen kecil. Jika kualitas hampir seri, pilih SVG dengan perintah geometri lebih sedikit. IoU mengukur mask piksel gelap, bukan semua warna. Penghitungan segmen dari token command SVG bersifat perkiraan.
